# Hello FanMa 

2024年03月30日

玥玥早晨七点多就过来我家，她要在我家里写作业。

下午的时候，我从山上回来，一见门就看到依依和一个小男孩跟着玥玥一起看电脑。

依依今天很少说话，她只知道笑。依依以前不是这样的，她变得不爱说话了，她变得不那么主动了。

和依依一起玩的那个小男孩口袋里有一个打火机，他经常拿出打火机出来玩。还在外面捡地上的烟头，还教依依抽烟，我都制止他好几次了，他还是还是经常捡地上的烟头来玩。

依依和这个小男孩在玩的过程当中，遇到一些小冲突，这个小男孩总是去打依依。

我跟玥玥说了，要她管好妹妹，不要让她去抽烟，不要让依依总是让人打。

2024年03月31日

依依不敢表达。

依依奶奶来我家里给她送衣服来，她奶奶跟她说，回去找奶奶的话，她就在二楼。

玥玥就说，她不想回去，就想要在这里。

奶奶一直跟依依说话，但是依依一句话也没有回她。但是奶奶回去时，她也跟着回去了。

依依现在话都不敢说了，不像以前，她说话声音都很大，她不想回去的话，她就会很大声地说：“我不要回去。”

刚才依依看到窗户旁的笔记本电脑，她就指着这个笔记本电脑看着我，她意思是想要看笔记本电脑里的视频。在这个过程当中她就没有说过话，只知道啊啊嗯嗯的。

现在她连说话都不敢说，连表达她心里所想都不敢了。

依依也许不想回去，但是看到奶奶来找她，她可能觉得奶奶要她回去，她就跟着奶奶回去了。

我写这些，并不是想希望依依一直在我这里，她还没吃早饭就过来我这里了，我也希望她回去先饭。而且依依回去了，我就可以去山上去了。依依在这里，我不放心离开，玥玥只顾着自己看电脑，不会看着妹妹的。玥玥一个人在我家里的话，我可以去山上一趟回来都没事。

依依有好长一段时间没来我这里了，在这一段时间里她发生了很大的变化。这些变化对她来说很不友好，我希望她可以变得更好，而不是变得越来越差。

我希望她不在我身边，她可以有更好的环境，让她变得越来越好。
