# Hello FanMa 

2024年07日16日

玥玥的干妈往我这边丢垃圾，她自己家和我家的垃圾桶都在旁边，她都不丢，就是要往我这边丢垃圾。刚好被我撞个正着被我看见了，她看见我后就立马转身走了。我看到这个情形后，什么也没做，只记在心里。

下午十三点五十六分左右，我在房间里看电脑时感觉脚有点凉，于是我就把风扇关了。

十九点五十分左右，由于房间里有蚊子，于是我就打开了风扇。打开扇风后，发现脚被风吹着有点凉凉的，如果吹久了就会着凉了，要盖上被子才行。风扇有四个档位，我只开一档，一档是最低的档位，风速是最低的。而且我开了摇头的，风扇并不是一直吹着我的。

去年的这个时候，晚上开着风扇都是风都是热的。而且当时用的不是这个风扇，那个风扇尺寸要比这个要大，风量会更大，当时我还是开最大档的，吹着也没有现在这个舒服。

我房间的窗户是关着的，因为窗户后面对角的一户人家在水缸里泡了一只死鸡，里面长满了很多蛆，有一股很大的臭味。
