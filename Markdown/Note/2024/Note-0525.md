# Hello FanMa 

2024年05月25日

今天中午依依在我家玩时，她自己会脱口而出说飞檐走壁。一开始我不知道她说的是什么，她一直说了好几遍才知道，她说的是飞檐走壁。然后我就跟她一起说飞檐走壁，我也陪着她一起时不时就说飞檐走壁。

我们一直就在桐桐姐姐的房间里玩，她就喜欢在床上玩耍。后面她玩一个球一样的玩具，但是不是球，她就喜欢这个球一样的玩具往墙上扔。她还在嘴里碎碎念“One、Two、Three”后，才把手上的球扔出去。一开始我也不知道她说的是什么，后来我才明白，她说的是One、Two、Three。后面我又跟着她一起说One、Two、Three，陪着她一起玩。

我可没有教过她这些，可是她自己就会说。有时候我会发现她有一些很有意思的事情，我就问她：“是谁教你的呀？”她就说“是自己教的。”我就说：“哇，你好棒。”。

依依很喜欢在我这里看电脑，自己在电脑里刷短视频看，可能是在短视频里看到相关的内容，她自己就学到了，然后就会脱口而出，学会我们没有教过她的知识。

今天我还第一次听到依依说“我的天哪！”这句话，我听到这句话后感到非常地开心。因为这句话是我教给她的，她之前时不时就会说一句脏话出来，后面我就引导她说“我的天哪！”，让她用这句话来代替她经常说的脏话。一开始她可能不太习惯，因此她就一直没有说过这句话。直到今天在桐桐姐姐的床上玩的时候，我才第一次听到她说“我的天哪！”

在桐桐姐姐房间里玩的这段时间，她就没说过一句脏话，她已经学会了用一些美好的词汇来代替。这是非常有意义的事情，是非常难得的，这也是依依成长的美好时光。
