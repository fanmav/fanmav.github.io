# Hello FanMa 

2024年03月16日

今天上午十点半左右，我从山上上完厕所顺便带了柴火回来。在回来的路上，依依看见我回来后，就是一喊：“大叔~大叔~~~”我一直没有回应她，一直没理她，可是她还是一直追着我。在这期间，她一直说：“我去你家找你，你家门都关了，我都打不到你。”直到到了我家附近时，我才回头看了一下她，才跟她说了几句话。

到了我家后，她还说：“你家门都关了，我都进不去。”我就跟她说：“你要是看到我家门关了，你就回家去呀。”

我并不想依依来我家里玩，其实我也想她来我家里玩。今天她快追到我时，我实在是忍不住才回头理她的，她太可爱了，我真的不想她难过。我知道，依依的家人并不喜欢她来我家里玩，因此我希望依依听家人的话，不要来我家里玩。

依依来到我家后，我拿相机给她拍了几张照片。接着就让她在电脑上看视频，在看视频时，她跟我说：“你都不带我去山上玩。”我就跟她说：“现在山上到处是湿的，等出太阳再带我去好吗？”她指着门口外面阴天照射到房子里明亮的光说：“你看，那不是太阳吗？”我说：“不是，那不是太阳，今天是阴天，没有太阳的，等有太阳了再带你去山上。”经过我的解释，她最终还是理解了我的意思，不再坚持自己的观点了。

我给也拿了几颗糖给她吃，她刚吃了两颗糖，可能觉得好吃，她就伸着手指头对我说：“我还要这么多。”她就是要很多的意思，于是我就把所有糖都给她拿了过来。

我前几天从河里捕了一些鱼回来，我就去鱼池里捞了三条出来给依依玩。然后我就要她拿回去玩，这样她才肯回去。不知道什么时候，她自己把刚才我给她的糖用一个小杯子给装起来了，顺便也把这些糖给她带回去了。

她双手拿着用一次性碗装着的鱼，她一边走路一边用另一只手不停地在碗里抓鱼。我要她先别玩，等回到家再玩，可她就是不听我的，就是要这样一边玩着鱼一边走回去。衣服和裤子上沾上水了，她也完全不在意。

走到一半路时，遇到了依依的奶奶，她奶奶就说：“你又玩水？”依依就说：“没有，我在玩鱼。”依依奶奶又说：“刚刚玩湿了才给你换的衣服，你现在又玩水。”我把依依送到她奶奶身边，我就转身回家了。

2024年03月22日

今天十八点四十二分，依依又偷偷跑来我这里，她要去冰箱那里找吃的，里面也没有什么吃的，我就把上次帮玥玥用饮料做的那个冰拿出来给她吃了。十八点四十四分时，她哥哥就过来带她回家了。

2024年03月24日

我去山上上厕所，顺便带点柴火回来，在回来的路上，看到玥玥和依依在玩耍。依依看到我后，她就跟我说：“我要去你家玩。”随后她就跟着我，要去我家里玩。

在去我家的路上，依依在一个大垃圾桶旁边看到一瓶饮料，这瓶饮料被人丢弃在这个大垃圾桶旁，还有很多饮料在里面。依依伸手就要捡起来喝，她奶奶看见了就要她不要捡来喝，并叫她丢垃圾桶里去。我也对她说不能喝，同时也要求她丢垃圾桶里去。

虽然她没有捡来喝，但是她并没有把它捡起来丢垃圾桶里。

以前我带着依依经过这个大垃圾桶旁边时，她在这里看到垃圾就会自己主动捡起来丢到比她还高大的垃圾桶里去。

依依自从上幼儿园以来，她就少来我家里了。在这很长的一段时间里，她就只来过我家一次。
