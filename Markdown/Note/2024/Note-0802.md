# Hello FanMa 

2024年08月02日

今天依依在我这里玩水的时候，她对我说：“大叔，那个倒了。”我说：“没事，它倒了就倒了吧，那是下雨的时候倒的。”她说：“是我弄倒的。”我就说：“没关系，反正它自己也会倒下的。”

自从7月11日丢一次垃圾后，至今我还没有把垃圾丢出去。

今天我去山上上厕所时，在一个小水坑里看到长了几株芦苇。而且其中有一株还长了一根芦苇棒，也就只有这和株长了芦苇棒。

这是我生平第一次在我们村看到芦苇，以前从来没有见过。在我很小的时候，那是在上小学的暑假里，我带着我妹妹还有村里比我小的几个小伙伴，我们去前面隔壁村里采摘芦苇棒来玩。

这是原本是一件很好玩、很愉快的事情，很可惜这一切并不是那么完美的。

当我们每人手上都拿着芦苇棒正往走时，被这个村子里的几个小孩看到了。他们把我们刚刚采摘的芦苇棒抢了回去，而最后唯独没有抢我手上的这两根芦苇棒。
