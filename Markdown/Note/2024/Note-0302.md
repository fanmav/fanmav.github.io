# Hello FanMa 

2024年03月02日

上午十点钟左右，我就听到依依在外面喊我，我打开大门，也没看到她。接着我就走出去找她，刚一出门口她就从我家左侧门的方向走了出来。

以前我家左侧门一直是开着的，即使是晚上也不会关的，由于最近这些天天气非常寒冷，我就会把那扇门给关了起来。依依以前来找我，她看到大门是关着的，她就会从那扇门进来，直到我房间门口才会喊我。

听玥玥说依依现在上幼儿园了，这是她第一次进幼儿园上学。再加上这些天也比较冷，因此玥玥和依依已经有将近十天没来我这里了。依依看到我后，她就展开双手向我飞奔而来，到我身边后就和我来个大大的拥抱。好多天不见了，她可能是太想来我这里玩了。

依依来到我这里，我就给她在电脑放视频给她看。她看了一段时间后，我就送她回去，可是我把她快送到家时，又要让我抱她，她要在我家玩，没办法，只好又把她送回我家了。她在我家又继续在电脑上看视频，没一会儿，她奶奶就过来找她，可是她就是不肯跟奶奶回去，就是要在我这里。

最后她奶奶也拿她没办法，只好让她继续留在我这里，她就自己回去了。

又没过多久，玥玥拿着作业本就来我家里了，她来到我家里，就占用了依依在看的电脑。她就是要一边看电脑，一边做作业。依依也不和姐姐争抢，好像就已经默认了这台电脑就是姐姐似的。

为了让依依也有电脑来看，就让她去我房间里，用我的电脑看视频，依依就把鞋子脱了到我床上看电脑

把她们都安顿好后，我就去厨房做饭吃了，都已经快到中午了，我还没有吃饭呢。在我做饭期间，她们俩很平静，各看各的互不干扰，就这样持续了很久。

就在我饭快做好的时候，我就看到依依没穿鞋子就跑出来了，她还在每只脚上垫了一个泡沫，为了防止袜子给弄脏。我看到她后，就帮她把鞋子穿好，穿好鞋子后我就送她回去了。

我做好饭后，就先自己吃饱饭先，吃饮饭后就去山上上厕所。玥玥还在我家里写作业，我就跟她说：“我要去山上了，你要是想在我这里吃饭的话，就等我回来再帮你煮。”她就说：“我都还没吃早餐呢，我肚子都饿了。”

我就跟她说：“那你先吃点零食先。”我就找了一个饼给她，让她先垫一下肚子先。她还跟我说：“我还要吃上次那个蒸鸡蛋和鸡蛋饼。”我说：“好的，等我回来先。”

就这样我去了趟山上，回来时顺便带了些柴火。我每次去山上，都顺便带一些柴火回来。

今天去山上的时候，那只小黑狗又跟着我去山上去了。就是以前我和玥玥还有依依去山里野餐，这只小黑狗就跟着我们一起去。上次玥玥在我家遇到这只小黑狗，就想要我找吃的给它。这是这只小黑狗第二次跟着我去山上了，前一阵子我一个人去山上的时候，它就跟着我一起去山上，算上和玥玥还有依依那一次，就是第三次了。

回来后，我就给她做了蒸鸡蛋和鸡蛋饼给她吃，而且只给她盛了一点点饭。最后她也没吃多少，那一点点饭都没吃完，鸡蛋饼倒是差不多吃完了。她吃好饭后，就又继续写她的作业了。今天她在我这里做作业时，我全程不管她，也不问她，全凭她自己安排。

傍晚十八点半的时，玥玥收拾好作业就准备回家，她一走出门口，就自己去摘了一些野果。这些野果很酸的，她也没多少，应该就只摘了几颗吧，然后她就回家了。

这时我在外面听到有人说话的声音，我也不知道是哪来的声音。然后我就在房子周围随便走走，当我走到房子左边的这一块地里时，就发现黄立涛和那个打过黄生的孩子，他们在路边偷偷摘我种的那棵野果来吃，他们看见我后就跑走了。

平时他们见了我可不会跑，只有做了亏心事才害怕的跑走了。

## 结语

即使依依有好多天没有来我这里了，但是她依然还是很喜欢来我这里玩。尽管我做的饭菜不好吃，玥玥还是想要吃我给她做的食物。我也希望她可以多吃点，但是我可能做得不合她口味，她每次都是没吃多少，就不吃了。有好多次，玥玥在我这里都是饿着肚子的，就算中午没吃饱饭，她还是要在我这里很晚才回去，今天她回去还算是蛮早的。我也想她可以在自己家里写作业，在自己家里好好的吃饭，可她就是喜欢在我这里。（内容整理日期：2024年03月02日，作者：黄胜丰，地址：广西壮族自治区富川瑶族自治县新华乡上坝村。）
