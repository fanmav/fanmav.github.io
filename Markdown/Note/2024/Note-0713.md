# Hello FanMa 

2024年07日13日

今天依依买买东西，老板不在家，她就想把钱从门缝里塞进去。因为玥玥小时候就这样做过，她还做了三次。昨天我对依依说：“以前姐姐买东西的时候，老板不在家，她就把钱从门缝里塞进老板家里。她还塞过两次。”玥玥听到后，就说：“是三次。”没想到过了这么久了，大概有两三年了吧，玥玥还记得她小时候的事情。

可是依依怎么也没能把钱从门缝里塞进老板家，她还曾经求助我，让我帮她塞进去，可是被我拒绝了。

其实依依要比玥玥聪明得多，她学习东西要比玥玥快。可是玥玥在依依那么大的时候，她是怎么做到的呢？她是怎么把钱塞进老板的家里的呢？这个可没有人教她，玥玥每次去买东西都是我送到小卖部旁边，然后就让她自己去买的。

玥玥第一次把钱塞进老板家里，我都大吃一惊。我质问她怎么能把钱塞进老板家里呢，还要她以后要是老板不在家，就不要把钱塞进去了。可能是由于当时她还小，还不能理解那么多，后面她才又塞进去两次钱到老板家里。

当玥玥第一次有塞钱进老板家的想法时，她就会自己思考，自己想办法怎么把钱从门缝里塞进去。可想而知，玥玥第一次塞钱时应该也不是很顺利的，她应该也是在门前观察了许久，找到可以塞钱进去的地方，她才能够把钱人门缝里塞进去。

玥玥自己想出来的点子，经过自己思考，自己去做的时候，她就会变得很聪明。

依依从姐姐那里知道，可以把钱从门缝里塞进去。可是她只是模仿姐姐做过的事情，去重复姐姐所做的事情，她并没有去独立思考，这也并不是她的本意。她只是知道钱是可以从门缝时塞进去的，因此她就省去了思考这一环节，这并没有加入她自己的想法。在这方面，她就不如小时候的玥玥。

其实玥玥小时候是也是很聪明的，我觉得现在玥玥并没有小时候那么聪明了。

因为玥玥现在做作业总是不想自己帮，总想着要我帮她写出答案来。而且她在家里的时候，做作业总是要人去教她。其实我最希望的是，她自己的作业能够自己完成，不需要其他任何人去教她。她现在做作业就是太依赖他人了，导致她现在的学习成绩并不是很好。

2024年07日14日

之前依依拿着家人给她的十一元钱，放在了我这里。放在我这里有一段时间了，最近这几天，她才拿着她这些钱去买零食吃。不过这些钱不只是她自己一个人用，她是和姐姐一起花的。最近这几天依依和玥玥每天每人大概花一两元，有时候花三元。

今天上午的时候，依依把最后剩下的两元钱花完了。到了下午快到傍晚时，她还想要去买东西。就又在我这里拿着之前她放在我这里的两毛钱，打算又要去买零食吃。我担心她钱不够，于是我就又找了两张一毛钱的，然后又找了一个一毛钱的硬币。

我就着她去最近的一个小卖部买，可是老板没在家，我们就去另外一个小卖部买。

到了路上的一个小卖部后，我就让她自己进去买的。可是她进去了许久都没见她出来，后来我就依稀地听到老板娘的声音：“你这个买不了东西的。”

然后我就走到小卖的大门口对依依说：“依依，快回来，你那个钱买不了东西的。”接着老板娘就说：“她这个钱不够，只有四毛钱。”

我就说：“她拿够了五毛钱的。”她就说：“她这里只有四毛钱。”我又说：“我给她拿够了五毛钱的，还有一个一毛钱的硬币。”

老板娘就问依依：“你那个硬币呢？”我就对依依说：“依依，快把那个硬币给她。”最后老板娘说：“那个硬币她自己握在手里的。”

最后依依就买了一包她自己喜欢吃的零食，我们在回来的路上看见了她奶奶，我就要她去奶奶那里了。

可是过了没多久，当我正在煮饭时，依依又跑过来我家来了。没一会，她奶奶就过来找她了，我就要她跟着奶奶回去了。
