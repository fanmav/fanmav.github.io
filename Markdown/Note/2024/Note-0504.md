# Hello FanMa 

2024年05月03日

玥玥和依依在一起玩时，依依头不小心碰到了玥玥的下巴。可能弄疼玥玥了吧，她就很用力的扇了依依一巴掌，然后依依就哭了。我就跟她说：“妹妹她不小心碰到你的呀，你怎么那么用力打妹妹呢？”她就哭着说：“她就是故意的。”

看来确实弄疼她了，她也哭了。但我还是继续跟她解释道：“妹妹是真的不小心碰到你的。”我确实看到了，依依是真的不小心碰到玥玥的。玥玥继续哭着说：“她就是故意的。”

此时妹妹就哭着，要我抱着她去找妈妈，她妈妈不在家，我就送回她奶奶那里了。

玥玥就回到我房间里，就自己一个人看电脑。

2024年05月04日

早上的时候，依依自己一个人来我家里玩，一开始她就要看电脑。我就帮她开机，她就说：“我不要你帮我开，我要自己开。”接着她就按电源开关键就把电脑关了，然后就自己再次按下开关把电脑打开。

她很喜欢在电脑上看短视频，以前都是我帮她打开视频软件给他自己看的。

她正在打开电脑时，我就离开了一小会，等我回来打算给她打开视频软件时，发现她正在看视频了，她自己就把视频软件给打开了。

可是我从来没有教过她如何使用鼠标去操作电脑，我只教过她按键盘上的上下方向键来滑动视频而已。

她可能经常看我使用鼠标操作，有时候她自己也会去摸那个鼠标动来动去，当时我还以为是她觉得好玩而已，没想到她是想自己使用鼠标来操作电脑。可能之前还没有熟练，就没有成功过，没想到今天她却自己成功地使用鼠标来操作电脑了。

要知道对于一个三岁多的小孩来说，移到鼠标指针都不是一件容易的事情，而且她还把指针移到她想要的位置，这个是比较困难的，但是她就是帮到了。最重要的是，把鼠标移动要打开的软件的位置后，还要双击鼠标才可以打开的。这个我可从来没有教过她的，但是今天她就打开了。

这是一件很神奇的事情，我从也没有跟她提过，鼠标要双击才可以打开软件，可是她就自己摸索就学会了。

可以看出，依依的探索与学习能力都非常好，而且实际执行操作能力也非常强。这是她非常好的一些特点，我们要鼓励她的这些特点，让她把这些特点很好地发挥出来，可以成为她最美好的东西。
