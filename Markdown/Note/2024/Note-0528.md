# Hello FanMa 

2024年05日28日

依依今天操作电脑熟练了很多，她打开短视频软件时，她用鼠标很流畅地就移动到准确位置，并且很快地双击打开了。她把鼠标移到短视频软件上后，她就在鼠标上一直点、点、点，当时我听到了很熟悉的双击的声音，虽然她多点了好几下，但是我能听到其中很正常的双击的声音。

今天我并没有提示她如何操作鼠标，可能是之前我给她讲过几次，她就一直牢记一心了吧，电脑一开机，她就自己很自然地拿着鼠标去操作了。

当她看视频期间出现需要扫码登录的弹窗时，她也能很迅速地使用鼠标把它关闭掉。

我觉得现在依依操作电脑比她姐姐还要好一些，玥玥现在操作电脑的时候都要用鼠标移动好久，才能把鼠标指针移动到正确的位置，而依依很迅速地就可以把鼠标指针移动到正确的位置。总而言之，在同样的操作上，依依所花的时间会比玥玥更短。

值得注意的是，依依所使用的电脑是没有鼠标垫的，她所使用鼠标下面就是垫在桌子上一张透明的塑料纸。而玥玥使用的电脑是有一块鼠标垫的，尽管这张鼠标垫已经破旧不堪了，但还是要比依依那没有鼠标垫的操作起来要好很多。
