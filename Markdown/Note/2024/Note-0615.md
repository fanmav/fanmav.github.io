# Hello FanMa 

2024年06日15日

今天一睡醒，我就在电脑上查看了天气情况，发现昨天晚上下雨下了有一百多毫米。昨天晚上我睡得并不太好，我迷迷糊糊地能听到下了好大的雨，于是才有了我一醒来就查看昨天晚上下雨的天气情况。

我起来出门发现，门口的鱼池里的鱼都跑出来好几条了，还有两条都已经死掉了，然后我就把没死的鱼捡起来把它们放回来鱼池里。

这个鱼池的水都满了，水都溢出来了，这才导致有些鱼跑了出来。好在跑出来的鱼并不多，里面还有很多鱼还在里面，没有跑出来。

这个鱼池从来都没有水满过的，可以看得出来昨天晚上下了很大的一场雨。而且昨天下的雨可能不止天气预报里的才一百多毫米，根据我这个鱼池进水量的情况，应该有超过两百毫米。

我想下了这么大的雨，河里面应该涨了很多水了，于是我就拿着相机去拍一些视频。

这时还是在下着小雨的，我就打雨伞拿着相机一边走一边拍。当我来到田边时，发现有几个人在田里发洪水的地方，其中有两个人在电鱼，另外两个人就在旁边站着，这两个人其中一人就拿着一个鱼网。

当我来到一条河边时，发现这条河的水都溢出来，有部分洪水都流到田里面去了。田中间有一条路有一小段都被水淹没了，那几个人就是在这里电鱼。

当我走近后才看清楚，站在旁边打着雨伞拿着一个鱼网的人，正是我们这里的村委书记黄进满。

我从他们这里经过后就继续往前走，到另一条比大一点的河那里看看。田中间这条路上的洪水就是从那条河里流过来的，可见那条河的水有多大。

来到这条大一点的河旁边，我就看到这里变成了一片汪洋大海。虽然前几年这里修了一道河堤，但是还是这次洪水的爆发，还是有一些洪水从河堤的一些缝隙中流了出来。

这是我见过这里最大的一次洪水，这个河堤的作用还是起有很大的效果的，不然这条河旁边的田里的水稻就会被洪水给冲走了。

当我往回走的时候，回到田中间被洪水淹没的这条路上。黄进满和另一个电鱼的人也正往这里走来，那个电鱼的人看到我拿着相机后，他停顿了一下，可能是有点担心我会拍到他什么的。不过的来不知道是什么原因，打消了他的顾虑，他就来到了洪水淹没的这条路上继续电鱼。

我仔细一看，才看清楚他，原来他就是黄成的爸爸，也是我们村里的村干部。

刚才我就发现我们的村委书记黄进满和这位电鱼的村干部一直走在一起，他们应该是一起合作的。因为在他们身边就只有一个水桶用来装鱼，而且村委书记黄进满就拿着一个鱼网就站在旁边一直看着，他也没有怎么去捞鱼，偶尔我才看见他去捞几下。

我回到家后，发现依依来找我了，她就在我家厨房里坐着等我回来呢。她看到我后，就过来对我说：“大叔，我过来找你，都打不到你。”我就对她说：“我都出去了，去看洪水里，外面发了很大的洪水。”

我跟她闲聊几句后，我就打开电脑给她玩了。她现在看电脑上瘾了，一来就要看电脑。

下午十七点多时，我发现有一个人往我家的菜园的方向吐口水，可能是由于他看到我了，他才没把口水吐到菜园里来。

我站在我家的右侧门口，有一个人骑着电动车往回他家的方向行驶，当到我家右侧门前的菜园时，他就转了个头向我家菜园的方向吐了个口水。他转头时正好看到我了，可能正是因为这样，才没把口水吐到我家菜园里来。（为什么非要往我家菜园的方向吐口水，一边是没有菜的，另一边是有菜的，为什么非要往有菜的方向吐口水。）
