# Hello FanMa 

2024年02月14日

玥玥和可可、茜茜去小卖部买零食，依依从爷爷那拿了二十元钱，跟着她们后面也要去买零食。由于老板不在家，她们没有买到零食就往回走了。回来的时候依依手上的二十元钱变成了一元，她那二十元就到了茜茜手上，我要依依去换回来，茜茜就不肯换，我跟茜茜说了，这是她爷爷给她的钱，要给回她爷爷的，她还是不肯给回依依。最后玥玥跟茜茜说了，是她爷爷的钱，茜茜才肯和依依换回来的。

在玥玥和依依在桂林过年回来的前一两天，可可在我家里玩纸飞机。后来茜茜也过来跟可可玩，她也要玩纸飞机，然后我就带着她们去拿之前我折好的纸飞机。

我之前把折好的纸飞机放在了桐桐房间里的一个桌子抽屉里，我打找那个抽屉把里面的纸飞机拿了出来。茜茜看到里面有几张一毛钱的纸币，她就把这几一毛钱的纸币全部拿走了。

这几年来，玥玥一直知道这里有纸币，她也从来没拿过这里的纸币来用。在前一段时间，依依从这里拿了五张一毛钱的纸币去买东西，之后就再也没拿过了。

今天我把玥玥和可可的画笔收拾好，还把玥玥拿来我家的玩具全部装在一个袋子里，最后我就把这些物品全部拿回了玥玥家。我还跟玥玥说，要她们从明天以后，就不要来我家里玩了，要她们在茜茜家玩，在外婆家里玩。

可可就跟我说：“要是茜茜不在家，我就来你家玩。”我就说：“那你可以去外婆家玩。”她又说：“那外婆不在家呢？”我就说：“跟你哥哥玩。”她又说：“那哥哥不在家呢？”我就说：“那你可以跟妈妈玩”……

总之她就是舍不得，玥玥其实也一样，玥玥现在不敢表达了，以前她很爱表达的，现在她都不会自己心里所想的东西给表达出来。

2024年02月15日

今天玥玥来我这里玩，我不怎么搭理她，她自己在外面看电脑。她在看电脑的时候，我就去山上上厕所去了。以前我每次上山，我都会跟她讲我去山上了，今天我没有告诉她。
