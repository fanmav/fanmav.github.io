# Hello FanMa 

2024年06日17日

今天早上依依没去上学，她就过来找我玩，原来她发烧了。她一进我家，就把拖鞋脱掉了，然后我就给她拼了个地板，不让她直接踩在瓷砖板上。

昨天我母亲一大早就把地板拖得湿湿的，当时我看到就非常生气。前一天她就拖了一次地，把地板弄的湿湿的，昨天又再拖一次。我们这几天一直在下雨，地板弄湿了，要好久才会干的。

依依昨天在我这玩，她又是脱鞋子，还时不进坐地板上或躺在地板上玩。地板上都是湿的，依依就是因为这样才会弄发烧的。

依依就是爱玩，在地板上玩也是她的一种兴趣爱好，不可能管着她这不给她玩，那也不给她玩。她现在已经看电脑上瘾了，她还能不一直看电脑，玩一些有运动的活动这是非常好的一件事情。

地板上的泥土它并不脏，它再脏也脏不过人心。

本来好好的地板，非要天天去给它弄湿，还天天都是下雨天，地板怎么能干得了。
