# Hello FanMa 

2024年08月22日

依依想去山上捡垃圾，我就跟她说：“今天下雨不能去。”。

依依在我家玩着玩着，就拿着我给她用竹子做的没鱼钩的钓鱼杆说是要去钓鱼。她说不要带姐姐去，于是我们就把玥玥留在我家里出去了。

在路上的时候，我就跟依依说：“小孩子不可以去玩水的。”她就说：“你不是大人嘛，有大人在就可以玩的。”我就蹲下来说：“你看，我也是小孩。”她就用手拉扯我的衣服，想要我站起来：“你是大人，不是小孩。”

下午玥玥知道刚才我跟依依没有带她去河边玩，她就又要我带着她们出去河边玩。我们河里发现了很多福寿螺，我捡了一些福寿螺出来，给玥玥把这些福寿螺都踩死了。

以前我来这里捕鱼的时候，每天都捡了一些福寿螺出来放到河边的水泥板上，到大太阳的时候，就会把这些福寿螺全给晒死了。
