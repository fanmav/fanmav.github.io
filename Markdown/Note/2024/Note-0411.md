# Hello FanMa 

2024年04月11日

玥玥在早晨六点半左右就来我家，她一进我房间时，把我吓一跳。当时我还朦朦胧胧的，还没睡醒，当我看她玥玥突然就跑进我房间来时，我就被她惊吓到了，当时我害怕及了。

依依今天在我家说过十次以上脏话，玥玥一整天都没有说过一句脏话。

今天上午我们去山上捡了垃圾，玥玥还和以前一样，依然保持着很美好的特质。依依今天也捡了一些垃圾，可是相比她以前来说，她今天捡的垃圾很少，她已经不怎么愿意捡垃圾了。依依在慢慢地失去她很美好的东西，这是一种不好的现象。

下午的时候，依依还想要去山上捡垃圾，可是我没有同意。其实上午也是依依想要去捡垃圾，我才带着她去的。

2024年04月13日

玥玥在我家写完作业后，她就很开心地跟我说：“明天我还要来大叔家玩。”这几天过三月三，他们放了四天假，这几天里，玥玥天天来我家玩。

玥玥在我房间里写作业，她一边看电脑一边写作业。她原本喜欢在大厅里看电脑的，之前也在大厅里一边看电脑一边写作业。不过从昨天开始，她就又像从前那样，喜欢在我房间里看电脑，于是外面的电脑就这样空出来了。

这几天依依和黄利帅也经常来我家玩，他们有时候也想跟玥玥在大厅里抢电脑看。不过最后他们都被玥玥赶走了，他们不只在趁玥玥不在时，才可以在大厅里看电脑。今天外面的电脑空出来后，依依刚开始在大厅里看了一会电脑，但是她并没有看很久，只是看了一会她就没看了。

黄利帅看到大厅里的电脑没人用，他就自己去看电脑了。今天黄利帅看了很长时间的电脑，依依就一个人自己玩耍。依依看到黄利帅在那里看电脑，她也没有去跟他抢、和她闹，只偶尔去打扰一下他看电脑而已。依依还说过这样一句话，她说：“看电脑对眼睛不好的。”

黄利帅并没是第一天在这里看电脑了，以前他在这里也看过好几次电脑。有时候玥玥和依依回去了，他也没有回去，而是自己一个人留在这里看电脑。

今天我去山上，看到我种的枇杷树上只剩下三颗枇杷了，昨天我过来的时候，看到还有好几颗的。昨天我看到时还这些枇杷还没有熟，皮还是黄里带青色的。当然即使没有熟也是可以吃的，只不过会比较酸而已。我本想留着等熟了一点再过一摘回去吃的，没想到只隔一夜就快没了。

今天这棵枇杷树结的果并不多，大概只结了七八串这样子吧。

2024年04月14日

在今天上午的时候，我就去河里放了两个捕鱼笼，到了中午时，我就带着玥玥和依依去河里捕鱼。很遗憾的是，我们到了河边收捕鱼笼时，一条鱼都没有捕获到。虽然没有挺捕获到鱼，但是今天还是有一点意外收获的。

我们并没有爱到没有捕到鱼的影响，而是继续在河边玩耍。突然就听到玥玥对我说：“大叔，河里面有个竹笋皮垃圾，你帮我捞上来。”随后我就帮她把河里的竹笋皮垃圾捞上来，丢在了河岸边上。没多久，玥玥又看到河里有一个植物垃圾，这个垃圾比较好捞，于是她就自己用手上的竹棍把河里的一个植物垃圾捞了上来，顺手就把它丢在河岸边上了。

玥玥在河里发现红色的福寿螺卵，她就会使用手上的竹棍把福寿螺卵全给打碎，把福寿螺卵给破坏掉。她只要看见了福寿螺卵，她都不会放过，就会亲手把它们处理掉。

我每一次带她来河边，她都一如既往的这样去做，她不忘初心，把一份责任牢记在心中。
