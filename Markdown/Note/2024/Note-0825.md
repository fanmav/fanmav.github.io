# Hello FanMa 

2024年08月25日

玥玥和依依去买了零食吃，依依一打开零食就随手把包装纸丢在地上。我就说：“依依，不要乱丢垃圾。”说完我就帮她把垃圾捡起来了。

玥玥就说：“我不会乱丢垃圾。”接着她就想要去茜茜家玩，她就把一些零食交给我，要我帮她放在我家里，她只拿了一个巧克力吃。

不过没一会，她就回来了，她说她又不想在茜茜家玩。可是她手上的巧克力却不见了，应该是她给吃完了吧。

不过后来依依又去买了零食吃，她买了刚才姐姐买过的一种零食吃，刚才依依想要吃玥玥刚才买的那个零食，可是她没给妹妹吃。

我和依依回到路口的时候，看到了玥玥把刚才巧克力包装纸丢弃在了路上。因为刚才依依丢在地上的也是这种巧克力包装纸，所以我知道这就是玥玥丢在这里的。

下午我带着玥玥和依依去捞鱼，我们只捞到了一只小鱼。玥玥在河里看到了一只螃蟹，我就帮她捞了上来。在这期间，依依一直在吃手里的一根一根的吸棒糖粉。我要求她把吃完后的塑料垃圾放到我的衣服口袋里，她也很听话，每次她都很自觉地把吃完后的塑料垃圾放到我的衣服口袋里。

一开始是我要她把吃完后的塑料垃圾交给我，然后我在把塑料垃圾放我衣服口袋。她看到我这样做后，后面她自己就会主动来放进我衣服口袋里来了。看到依依有这样的进步后，我感到非常的开心。

其实在这之前，依依在我家看电脑的时候，她也是吃这个零食。我就在她坐着的椅子旁边放了一个垃圾桶，要她自己把垃圾丢进桶里来。可是她都没有记在心上，她还是把吃完的塑料垃圾随手就丢在了地上。

我捞鱼回来后，就在依依刚才看电脑时坐着的椅子旁边，看到了她丢弃在椅子周围一些塑料垃圾。
