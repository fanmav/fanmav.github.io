# Hello FanMa 

2024年08月29日

依依还没吃早饭就要去河里捞鱼，结果我们一条鱼都没有捞到就回来了。当我们回到依依家门口时，我就叫她喊“妈妈、奶奶”，她就很大声地喊：“妈妈、奶奶。”她奶奶听到后就回应道：“哦，我们吃饭喽。”

于是我就要依依先回去吃饭先，她也很乖地自己走回去吃饭了。其实在还没到依依家门口前，我就打算到她家旁边就要她先回去吃饭的。如果她了我家里，再想让她回来吃饭就很难了。昨天就是依依奶奶过来叫她回去吃饭，她都不肯，结果我还把她弄哭了。最后还是让她在我家里，她奶奶就回去把饭带过来在我这里吃的。

尽管如此，依依还是没有把饭吃完，碗里大概还剩下原来的五分之一吧。不过玥玥在家里吃完饭过来后，她就想要吃依依的饭。我想征得依依的同意后，再让玥玥吃。我就对依依说：“你的饭给姐姐吃了哦。”她本来也就不想吃了的，她就点了点头。

然后玥玥就拿着依依的饭碗进我房间里吃了，就这么一丁点的饭菜她吃了很久才吃完的。
