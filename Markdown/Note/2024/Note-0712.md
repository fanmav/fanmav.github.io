# Hello FanMa 

2024年07日12日

今天依依在我家很少说话，感觉她变了。下午的时候，来我家找姐姐，她看到我就跑了，好像很害怕我似的。

我突然发现，她今天没有叫过我一声，在今天之前，依依来到我家，她都会很自然地叫我一声：“大叔。”甚至一天都要叫我好几次。

其实玥玥有好长一段时间以来，她也很少叫我了。她现在来我家从来不叫我，现在她每天来到我家，老是“啊”的一声。

其实玥玥心里面是很想叫我大叔的，只不过是出于某种原因，她把它藏在了心里。

虽然玥玥现在来到我家里只会“啊”的一声，但是她会经常要我帮她拿东西或什么的，就会对我说“大叔，我要喝水。”“大叔帮我拿剪刀过来。”这其实只是玥玥在找借口来喊我一声大叔而已，她真是用心良苦。

之前玥玥跟我说她喜欢做作业，其实她并不喜欢做这么多的作业，只是她有作业，就有借口来我家里玩而已。因为她把作业拿过来，都是要我帮她写出答案来，她才肯做作业。不然她就会又哭又闹的。

玥玥在依依那么小的时候，我不用教她，她就会自己把垃圾丢在垃圾桶里。到现在玥玥还保持着，在我家里她会自己主动把垃圾丢到垃圾桶里，不再需要我提醒她。

而现在的依依，她会很自然地就随手把垃圾丢地上。之前我教过她，要她把垃圾丢垃圾桶里，而且她也听话，会乖乖地把垃圾丢进垃圾桶里。

明明依依已经教育好了的，不知道为什么依依现在会变成这个样子。

其实依依是很聪明的孩子，她的学习能力比玥玥还要好。可是爱学习的依依，却没有玥玥做得好。

可能学习能力好也是有两面性的，因为好的她会学，不好的她也会学。这样的孩子需要正确的引导，给她正确的价值观，才会健康向上的成长。
