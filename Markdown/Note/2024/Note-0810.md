# Hello FanMa 

2024年08月10日

下午依依上厕所的时候，她跟我说：“大叔，我拉出血来啦。”我帮她擦屁股的时候，她就说：“好痛。”我就对她说：“以后你要天天拉一次大便，这样才不会拉出血来。”

我看了一下她拉的大便，有大有小的类似一粒一粒的，其中还带有一点血。

玥玥以前也跟我说过，她拉大便的时候也会出血。我也跟也说过，要她每天都要拉一次大便，这样才不会出血。

我小时候大便的时候会出血，长大了也会。就是十年前，我就自己把它治好了，现在我大便从来不会出血了。

以前我拉大便出血的那个时候，基本上都是很多天才拉一次大便，而且拉一次大便要很久。

现在我基本上每天都要拉一次，而且拉一次很快就拉好了。

下午接近傍晚的时候，我捕鱼回来经过依依家附近，看到黄进满的老婆在依依家旁边烧火，也就是黄进满家正前方的偏左边一点。
