# Hello FanMa 


2024年04月15日

早晨的时候，我去山上上厕所，顺便带些柴火回来。在回到依依家旁边时，她看到我就大声喊：“大叔。”接着又说：“我想去你那里。”我对她说：“今天你要去上学，要在这里等校车，不要来我这里。”然后我还挥手跟着说：“拜拜。”

玥玥也跟着说：“我想去大叔家。”她大姑就跟她说：“等一下校车就来了。”

玥玥和依依在外面等校车，看到我后就想跟着我。

现在的依依在外面看到我后，会主动跟我打招呼，而且玥玥现在不敢跟我打招呼了。在玥玥还小一两岁的时候，她在外面看到我时，也会很勇敢的跟我打招呼。

中午的时候，我又去山上上厕所，发现我种的那棵枇杷树最后剩下的那一颗枇杷果也被别人偷摘去了。

前天我上去看的时候，还有三颗枇杷，其中已经有两颗差不多熟了，还有一个颗还是深绿色的。那两颗差不多熟了已经是可以吃了的，我就把它们摘回来吃了，只留下深绿色的那颗，准备留着它，等它熟了再摘了吃的。

没想到还没过两天，它就已经被人摘走了。这颗枇杷它还没熟啊，它还是绿色的，果皮一点淡黄都没有。
