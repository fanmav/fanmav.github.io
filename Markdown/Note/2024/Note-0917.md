# Hello FanMa 

2024年09月17日

今天在外面带玥玥和依依玩时，我就指着一个山头对她们说：“我前几天去过那个山顶上，上面有一个地方很平坦，我把那里的竹子砍了后，就可以去那里玩耍，以后我就在山面砍竹子整一条山路出来。”

玥玥听到后就很兴奋，也很想上去玩，她就说：“我也要去那里玩。”我就说：“等我把上面弄好先。”她就说：“好。”

依依也说：“我也要去。”

玥玥又对我说：“好，我们来拉钩。”接着我就依次跟玥玥还有依依拉钩：“‌拉钩上吊一百年不许变。”

回来后，玥玥就要我给她煮鸡蛋面吃，在我开始给玥玥煮鸡蛋面时，依依跑来厨房跟我说：“我也要砸鸡蛋。”我就对她说：“我不用过来，我帮你煮就是了。”她就说：“我不要，我就要自己来。”

我刚把锅里倒好油她就拿了一个鸡蛋开始在桌子上砸了，我就对她说：“那油还没烧好呢，等油好了再砸鸡蛋啊。”

还好她没把鸡蛋砸碎，不过鸡蛋壳上面已经出现了一条裂缝了。锅里的油烧好后，我就把锅拿下来放地上，鸡蛋给回她后，她就把鸡蛋砸开放进锅里了。

我帮她把鸡蛋壳丢进柴火灶里，她就指着橱柜最上面的盐说：“帮我把那个白色的拿下来。”我把盐拿下来后说：“我来帮你放盐好不？”她就说：“不要，自己的事情自己做。”

我就拿盐勺盛了一些盐给她，她就把盐洒在了锅里的鸡蛋上面。

我把这个鸡蛋煎好后，她就用手想去拿来吃，我就跟她说：“很烫的哦。”她就说：“给我拿纸巾包着吃。”

于是我就拿了一张纸巾包了一点鸡蛋给她吃，她吃完后还想要。我就拿了一个小碗，把整个鸡蛋都放进小碗里给她拿到电脑旁边吃。

当她吃到只剩下一点点的时候，就说：“好咸，我不说了。”应该是刚才她放盐时没有把盐洒均匀吧，导致一部分盐堆积在了一起。

就在这时，依依的妈妈就来找她回家吃饭，我就要她跟着妈妈回去吃饭，我还跟依依说：“姐姐就在这里吃面条，你就在家里吃饭。”

依依妈妈就问：“她在吃面条？”我就说：“我正在给她煮。”
