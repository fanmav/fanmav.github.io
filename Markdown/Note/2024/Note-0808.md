# Hello FanMa 

2024年08月08日

今天我去捕鱼回到玥玥家旁边，听到黄立涛很大声、很响亮地说了一句：“操你吗？”我一开始并没有看到黄立涛，当我看到他时，他就一直在那里很开心地笑。当时他就在黄进满黄书记大门口前的路上，和另一个打过黄生的男孩在一起。

在这个村说这样的话是一件非常开心，且是非常骄傲和自豪的一件事件，特别是在黄书记的门口说这样的话非常有自信。黄书记就非常喜欢这样的孩子，他就是喜欢说脏话的孩子和可以打人的孩子。

以前我看到过黄书记把手搭到黄立涛的肩膀上，有说有笑的，可以看得出来他们之间的关系非常良好。有一次黄生路过黄书记家去找玥玥，但是我没听到黄书记跟黄生打招呼。当黄生到玥玥家旁边时，那个打过黄生的男孩从黄书记家门口的正前方经过，黄书记就主动跟这个男孩打招呼。
